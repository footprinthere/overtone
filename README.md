# 가사 플로팅 (LyricsFloat)

유튜브 뮤직에서 재생 중인 곡의 가사를 다른 앱 위에 띄워 주는 개인용 안드로이드 앱.
빠른 설정(상단 패널) 타일로 켜고 끈다. 가사는 LRCLIB(lrclib.net) 공개 API에서 가져온다.

## 빌드
1. Android Studio(최신)에서 이 폴더를 Open → Gradle Sync
2. 폰 USB 디버깅 연결 후 Run, 또는 Build > Build APK(s)

## 최초 1회 설정 (앱 실행 화면)
1. 다른 앱 위에 표시 허용
2. 알림 접근 허용 (유튜브 뮤직의 재생 정보를 읽기 위함)
   - 설치 직후 회색으로 막혀 있으면: 설정 > 앱 > 가사 플로팅 > ⋮ > '제한된 설정 허용'
3. 알림 표시 허용 (Android 13+)
4. '빠른 설정에 타일 추가'

이후에는 상단 패널의 '가사 플로팅' 타일을 탭하면 켜지고/꺼진다.
