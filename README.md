# 오버톤 (Overtone)

유튜브 뮤직에서 재생 중인 곡의 가사를 다른 앱 위에 띄워 주는 개인용 안드로이드 앱.
빠른 설정(상단 패널) 타일로 켜고 끈다.

가사는 LRCLIB(lrclib.net) → 벅스 → 지니 → 멜론 순서로 찾는다. 싱크 가사를 찾으면 거기서 멈추고,
끝까지 싱크 가사가 없으면 처음 찾은 일반 가사를 보여 준다. 벅스·지니·멜론은 공개 API 가 아니라
웹페이지를 읽는 방식이라 사이트가 바뀌면 그 출처만 실패하고 다음으로 넘어간다.

## 빌드
- Android Studio에서 이 폴더를 열고 Run, 또는
- 명령줄: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
  - 폰 연결 후 바로 설치: `./gradlew installDebug`
- 단위 테스트: `./gradlew testDebugUnitTest`
- 공유용 APK: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
  - 서명 열쇠 경로와 비밀번호는 `~/.gradle/gradle.properties` 의 `OVERTONE_STORE_FILE`, `OVERTONE_STORE_PASSWORD`,
    `OVERTONE_KEY_ALIAS`, `OVERTONE_KEY_PASSWORD` 에서 읽는다. 이 값이 없으면 서명되지 않은 APK 가 나온다.
  - 업데이트는 같은 열쇠로 서명해야 설치되므로 열쇠 파일과 비밀번호를 잃어버리지 않게 따로 보관한다.

## 최초 1회 설정 (앱 실행 화면)
1. 다른 앱 위에 표시 허용
2. 알림 접근 허용 (유튜브 뮤직의 재생 정보를 읽기 위함)
   - 설치 직후 회색으로 막혀 있으면: 설정 > 앱 > 오버톤 > ⋮ > '제한된 설정 허용'
3. 알림 표시 허용 (Android 13+)
4. '빠른 설정에 타일 추가'

이후에는 상단 패널의 '오버톤' 타일을 탭하면 켜지고/꺼진다.

## 가사 창 사용법
- 여러 줄 모드: 윗줄을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꾼다. 위치·크기는 기억된다.
  - 윗줄 오른쪽 버튼은 왼쪽부터 얇게 · 접기 · 더 보기 · 닫기 순서다.
  - 두 줄 아이콘(얇게): 지금 줄과 다음 줄만 보이는 얇은 띠로 바꾼다. 띠를 탭하면 다시 펼쳐진다.
  - 점 세 개(더 보기): 싱크 보정(0.5초 단위, 곡마다 기억), 다른 가사 고르기(모든 출처의 검색 결과), 터치 통과 켜기
- 가로줄(접기): 창을 가까운 화면 가장자리의 앱 아이콘 모양 버튼으로 접는다. 얇은 띠에도 있다. 아이콘을 탭하면 다시 펼쳐지고, 끌어서 옮기면 가까운 가장자리에 붙는다.
- 터치 통과: 가사 창을 눌러도 밑의 앱이 눌린다. 끄려면 알림의 '터치 통과 끄기'나 앱 설정 화면을 쓴다.
- 유튜브 뮤직을 일시정지하면 창은 그대로, 종료하면 숨겨진다. 다시 재생하면 나타난다.
- 배경 불투명도·글자 크기는 앱 설정 화면에서 바꾼다.
- 한 번 찾은 가사(직접 고른 것 포함)는 기기에 저장해 두고 다시 받지 않는다.

## 디버깅
`adb logcat -s Overtone` 로 곡 인식 결과(유튜브 뮤직이 넘겨준 원래 제목/가수와 정리된 값)와 요청 오류를 볼 수 있다.
